# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 汤色比色卡

交评时必须勾选汤色比色卡档位（浅 / 中 / 深三档卡片单选，不是下拉）。档位与汤色分有交叉规则，默认：

| 档位 | 汤色分 |
|------|--------|
| 浅档 | 汤色 < 5 |
| 中档 | 5 ≤ 汤色 ≤ 7.5 |
| 深档 | 汤色 > 7.5 |

- 档位与分数不符则**整笔拒交**，审评表与台账都不增行。
- 每次成功勾选落入**比色台账**，冻结当时的汤色分、档位、批次、提交人、时刻。
- 顶栏「比色卡专页」同页放规则表与台账，可按批次翻台账；规则表可改（仅审评员），改规则只影响新交评，旧台账行不改写。
- 观察员能看规则与台账，不能交评、不能改规则。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 汤色打 9 却勾浅档 → 拒交，审评表与比色台账都不增行；改勾深档 → 成功，详情页与台账都能看到深档。
5. 在比色卡专页把浅档上限改严（如 5 → 4）→ 旧台账行仍是原先冻结的深档；新交评按新规则校验（如汤色 4.5 只能勾中档）。
