# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

交评时必须勾选汤色比色卡档位（浅 / 中 / 深）。档位与汤色分有交叉规则：汤色分低于浅档上限只能选浅档，中档区间内选中档，高于中档上限选深档（默认 5 / 7.5 分界）。档位与分数不符则整笔拒交，库不增行。每次成功交评都会落入比色台账，冻结当时汤色分、档位、批次、提交人、时刻；事后改规则表只影响新交，旧台账行不回改。规则表与台账同在顶栏「汤色比色卡」专页，可按批次翻台账。观察员能看规则与台账，不能交评、不能改规则。



这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 再提交一组高分，新行出现在表头，页面不整页刷新。
3. observer 登录后没有提交表单。
4. 汤色打 9 却勾浅档，整笔拒交且台账不增行；改勾深档后成功，审评台与比色台账都能看到深档。
5. 顶栏进「汤色比色卡」专页：把浅档上限改得更严后保存，旧台账行仍是原先的深档记录；新交评按新规则判定。
6. observer 能打开专页看规则与台账，但改规则、交评都被拒（403）。
